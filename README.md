# FAGIS Console OS

![Banner](https://via.placeholder.com/800x200?text=FAGIS+Console+OS+-+Python+Based+Terminal+Environment)

Локальная консольная операционная система на Python с реализацией базовых команд и интерактивными функциями. Проект создан для демонстрации возможностей создания простых консольных интерфейсов.

## ✨ Основные функции

- 📁 Файловая система: команды `ls`, `cd`, `mkdir`, `touch`
- 📟 Системные утилиты: вывод времени/даты (`time`, `date`), очистка экрана (`clear`)
- 🧮 Встроенный калькулятор (`calc`)
- 🎮 Мини-игра "Угадай число" (`game`)
- 🔍 Система проверки обновлений через GitHub
- 📋 История команд (на базе стандартного ввода Python)

## 🖥️ Доступные команды

| Команда     | Описание                       | Пример использования       |
|-------------|--------------------------------|----------------------------|
| `help`      | Показать справку               | `help cd`                  |
| `exit`      | Выйти из системы               | `exit`                     |
| `clear`     | Очистить терминал              | `clear`                    |
| `time`      | Показать текущее время         | `time`                     |
| `date`      | Показать текущую дату          | `date`                     |
| `whoami`    | Показать текущего пользователя | `whoami`                   |
| `ls`        | Показать файлы в директории    | `ls`                       |
| `cd`        | Сменить директорию             | `cd Documents`             |
| `mkdir`     | Создать директорию             | `mkdir new_folder`         |
| `touch`     | Создать файл                   | `touch file.txt`           |
| `echo`      | Вывести текст                  | `echo Hello World!`        |
| `calc`      | Открыть калькулятор            | `calc`                     |
| `game`      | Запустить мини-игру            | `game`                     |
